# 共享文件夹分页与大目录下载

日期：2026-11-09。接续发射端模块对照中的文件浏览、文件夹下载缺口；参考版本仍为本地 RustDesk `7423dced37845c48093b6f71bd82e4a16cc8c79d`。

## 用户行为

超过 1024 项的共享目录现在可以继续浏览。观看端文件面板增加“加载更多”，显示已加载数量，追加页面时保留此前条目和选择。失败时可以重试当前页；切换目录或刷新后，旧回复不会把页面带回旧目录。未加载完的目录明确提示筛选只针对已加载条目；本地排序也只作用于已加载内容。

递归文件夹下载自动请求后续页，不再因为单个目录超过 1024 项而失败。保留现有共享根、路径校验、reparse point 拒绝、文件大小限制、遍历总数/深度限制、取消及断线清理。空目录继续在本地创建；它们也可以分布在后续页。

## 协议和主机

协议升级到 **v56**，部署时发射端和观看端需要使用同一协议版本。`FileListRequest` 在目录后增加长度加 UTF-8 游标，空游标表示从头开始；`FileListResult` 在条目后增加下一页游标，`truncated` 表示还有后续页，不再表示无法取得剩余条目。

游标由目录/文件类型与最后一个名称构成：`d:<name>` 或 `f:<name>`。名称按 UTF-8 字节序排列，目录在文件之前。游标不能携带路径，主机每次仍独立解析和校验请求的相对目录。响应严格验证条目顺序、重复项、后续游标与最后一项一致性；观看端还检查下一页确实前进，避免被重复页困住。

主机使用最多 1025 项的堆选取一页及一个前瞻条目，不再先把整个目录装进两个向量。完整枚举失败返回错误并清空部分结果，不伪装成最后一页。游标不依赖此前条目还存在，前页发生插入/删除时不会像数字偏移那样造成后页位移。

这是实时目录浏览，不是文件系统快照。每次请求仍会重新扫描目录；目录非常大或位于慢速存储时可能较慢。分页之间新增在游标之前的条目需要刷新才能看到；文件改名或类型改变也可能改变浏览结果。没有取消原有 200000 项遍历上限或其他安全边界。

- 既有文件浏览面板测试 50 项通过：`build/file-pagination-flutter-final.log`。包括追加、失败后同页重试及旧目录回复丢弃。最初两项旧断言分别依赖旧“截断”文案和未经请求的目录回复，已调整为实际请求与新分页行为。
- Dart 定向静态检查无问题：`build/file-pagination-dart-analyze-final.log`。
- 复用 `chast-viewer-probe --file-pages`，通过真实主机、观看端引擎、认证和 QUIC，分两页取得 1030 项；递归下载核对 1025 个新增空目录、原有嵌套结构及全部 4 个文件的内容，包含最后一页文件。见 `build/file-pagination-viewer-probe.log`。本次使用文件专用会话，没有采集屏幕或注入输入；临时目录和下载结果已清理。
