# 服务管理器随用户登录启动

日期：2026-11-09。接续 [服务机器设置](service-machine-settings-2026-11-09.md)。

后续更新：服务选择已补齐 RDP-only 回退、登录代次校验和完整快照失败处理，管理器增加服务状态与本地会话编号。见 [Windows 会话选择](windows-session-selection-2026-11-09.md)。本文保留启动阶段的验证范围。

## 用户行为

服务发现其当前目标 Windows 会话已有交互用户时，会自动启动同目录下的 `chast-host.exe --service-manager --tray`。它在通知区域运行，连接工作进程并接收 Click/Both 审批，无须用户每次登录后手动打开管理器。目标会话仍沿用现有的控制台/查看者指定会话选择策略。

普通启动默认配置的 `chast-host.exe` 时，只要服务已安装，就进入服务管理界面。服务处于延迟启动、停止或重启状态时，管理器等待工作进程，不会另开一个普通共享进程占用端口。也可以显式使用 `--service-manager` 打开管理器；该参数与 `--portable`、`--config`、机器设置编辑参数互斥。没有服务端点时只等待，不创建普通主机监听或改写其配置。

服务安装时若默认托盘主机已运行，其定时检查发现已安装服务后，会停止自己的共享、释放原窗口并进入服务管理流程。显式便携模式和其他配置路径保持原有模式。

服务运行期间，用户选择“退出连接管理”后保持关闭；下次重新登录或服务重新启动时再次尝试自动启动。管理器异常退出、缺少程序或用户令牌暂不可用时，间隔 10 秒重试并写服务日志。服务停止不会杀掉管理器，管理器可以等待服务重新启动。确认服务已卸载后，见过该服务的管理器自动退出；暂时无法查询服务状态不等于卸载。

同一 Windows 会话只有一个管理器。后台重复启动不会把已有隐藏窗口弹出来；手动启动可以打开已有窗口。单实例锁只请求同步访问，以便普通用户实例识别同一用户已经提升的实例。

## 身份和资源

新增 `host/service_manager_startup.{h,cc}`，由服务监督线程调用。启动器使用 `WTSQueryUserToken` 获取目标会话的交互用户，检查会话 ID、登录 SID 和非服务账户身份。遇到 UAC 的完整令牌时，采用同一登录的关联受限令牌。

子进程使用该用户的环境块和 `winsta0\default`，不继承句柄。程序路径固定为 `chast-service.exe` 所在目录的 `chast-host.exe`，不通过 PATH 搜索；服务安装在修改防火墙或服务项前检查这个文件存在。

管理器不放入工作进程的 kill-on-close Job；停止/重启工作进程不会结束用户界面。启动器按会话保存登录 SID 和进程句柄，处理登出通知并释放旧记录；登录 SID 改变时不会沿用上个用户“已退出”的状态。单次服务运行内，已正常退出的管理器不会被轮询重新拉起。

安装服务不再删除当前用户的普通主机开机启动项。旧的 `--tray` 启动入口会按“服务已安装”规则进入管理器；服务自身负责自动启动，无须写新的 HKCU/HKLM Run 项。卸载停止后不再有新的自动拉起来源，原有用户启动偏好保留。

## 验证与边界

主机、服务、既有设置/翻译测试构建通过。复用 `host_settings` 和 `host_i18n`，两项通过，耗时 0.20 秒，见 `build/service-manager-startup-regression.log`。没有新增 CMake 测试项目。

随后重新构建主机、服务和既有 `host_parity`，复跑真实管道与 QUIC 的 `--service-control` 场景通过，见 `build/service-manager-startup-final-build.log`、`build/service-manager-startup-control.log`。原生管理器辅助验证也通过，另以可控的服务存在状态验证“已安装→查询失败仍保留→确认删除才退出”的控件生命周期，见 `build/service-manager-startup-ui-check.log`；这不是实际卸载正式服务的验收。

忽略的 `build/service-manager-startup-check` 创建唯一命名的临时 SYSTEM 服务，调用真实产品启动器，并启动实际的交互用户进程。验证子进程 Windows 会话、用户 SID、UAC 令牌类型、USERPROFILE，及存活时不重复启动、正常退出保持关闭、登出记录清理、异常退出退避重启、服务监督对象销毁不杀子进程。临时服务与进程报告文件已清理；日志见 `build/service-manager-startup-check.log` 和 `build/service-manager-startup-system.log`。

`build/service-manager-entry-check.ps1` 启动真实 Release 主机程序，检查独立管理入口、隐藏状态、重复启动正常退出且不弹窗、拒绝便携参数组合、没有 UDP/TCP 主机监听、普通用户配置未改动以及正常退出。日志见 `build/service-manager-entry-check.log`。验证脚本首次窗口查询误把空参数当作空标题，修正查询后重新完整验证通过。

没有安装或更改正式 `chast-host` 服务，没有修改用户启动注册表项，也没有触发本机注销/登录。真实令牌启动和进程生命周期已验证；完整多用户/RDP 登录切换、无用户登录时的管理与采集、不同机器上的 UAC 桌面交互仍需继续实现或实机验收。会话内远程提权属于后续模块。
