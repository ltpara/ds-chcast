# 剪贴板异步读写与失败恢复（2026-11-07）

本次修复 RustDesk 对照审查确认的三个问题：查看器同步读取阻塞输入和视频、首次读取失败后误发历史内容、读写争用导致远端复制丢失。此前主机关闭等待剪贴板线程的边界也一并处理。

## 当前行为

- 主机和查看器都使用 `ClipboardWorker`。每个端点持有一个常驻执行线程，将文本/富文本、文件列表读取、文件目录展开和剪贴板写入串行执行。会话线程只提交任务和消费结果，不再调用原生剪贴板 API。
- 原生读取明确返回 `Failed`、`Empty` 或 `Content`。打开失败、已声明格式无法读取、部分格式读取失败都不会建立基线；确认无支持内容以及空文本才视为成功的空快照。首次有效快照只记录基线，不发送连接前的内容。恢复权限也重新建立基线。
- 最新远端内容保留在会话状态中。后台忙时等待；写失败后间隔 250 毫秒重试，总计最多 10 次。新收到的内容替换旧待写项；即使新内容与之前的基线相同，也会取消尚未应用的旧内容。
- 文本和已下载的文件列表使用相同的执行器和重试规则。成功后才更新接收计数及回显抑制状态，避免把自己的写入再次发回远端。
- 撤权、暂停和会话结束会取消排队工作，并使在途读取结果失效。查看器快速暂停后恢复也会通过版本号触发新基线。恢复主机权限时，在接收新复制之前初始化本轮状态。
- 重新连接复用原执行器；旧读取返回后丢弃结果，再启动新任务，避免一次慢读导致不断增加竞争线程。测试后端可以在下次 `Start()` 前重新配置。
- 关闭与析构不再 join 阻塞的剪贴板调用。执行线程独立持有回调和状态，系统调用返回后安全收尾，不访问已销毁的主机或查看器。

## 回调约定与边界

测试后端应在启动前安装，并通过 `shared_ptr` 等方式持有捕获状态；回调可能在端点销毁后才返回。富内容 bool 读取回调现在以 `false` 表示失败，`true` 且内容为空表示已确认空剪贴板。旧文件列表测试回调仍以 `false` 表示没有文件；生产 Windows 后端使用明确的三态读取。

无法强制中断已进入 Windows 的调用。取消阻止新的任务和重试，并丢弃迟到结果；已经开始的写入可能完成。执行器没有分离后继续捕获端点 `this`，也不会依靠强杀线程回收资源。

此次采用的是每端点一个常驻执行器，仍按 500 毫秒发起读取请求；没有实现 RustDesk 的跨会话共享、系统变更通知监听。因此这里描述的是上述缺陷的修复，不代表所有剪贴板架构都已与 RustDesk 一致。

## 验证

`clipboard_async` 使用真实主机、真实 ViewerEngine 和 loopback QUIC，四个剪贴板方向均为内存回调，键盘注入为 dry-run。覆盖：

- 两端首次读取失败后恢复，不发送历史内容；空基线后的第一次复制正常发送。
- 查看器慢读期间，按键按下、松开、释放请求和画面处理继续。
- 主机避免自身读写争用，两端写入失败自动重试。
- 新内容覆盖排队的旧复制，撤权及查看器本地暂停取消待写。
- 重试达到 10 次停止，后续新复制仍然正常。
- 重连更换后端且丢弃旧结果；两端慢读期间停止和析构不等待读取。

`host_control` 保留控制响应、撤权、回显抑制和跨会话验证，并将“读写同时进行”的旧断言更新为“写入排队、读取完成后执行”。`viewer_clipboard_files` / `viewer_clipboard_files_up` 覆盖双向文件复制。

最终定向 CTest **10/10 通过**，总计 54.44 秒：`protocol`、`keyboard`、`protocol_fuzz`、`host_multi`、`host_control`、`clipboard_async`、`host_login`、`block_input`、`viewer_clipboard_files`、`viewer_clipboard_files_up`。其中新增 `clipboard_async` 为 15.41 秒、0 个失败，覆盖上述重试上限、重连和取消边界。日志为 `build/review/clipboard-fix-regression.log`，详细断言输出位于 `build/root/Testing/Temporary/LastTest.log`。

主机和 Flutter Windows 查看器 Release 构建通过，产物为 `build/root/Release/chast-host.exe` 和 `app/build/windows/x64/runner/Release/chast_viewer.exe`；构建日志为 `build/review/clipboard-fix-build-final.log` 和 `build/review/clipboard-fix-flutter-build.log`。仍存在原有的权限窄化、宏重定义及链接库告警。`git diff --check` 通过。

所有相关剪贴板测试均使用内存回调，不读取或改写真实剪贴板；键盘和主机控制测试使用模拟后端，不执行真实键盘输入、锁屏、重启或输入阻止。此结果不代表整个 CTest 套件、跨机器物理键盘或真实 Windows 延迟渲染行为已全部实测。
