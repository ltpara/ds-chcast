## 2. 发现与修复

| 问题 | 修复与可观察行为 |
| --- | --- |
| 同账号撤权时，策略列表或编辑器的迟到响应仍可恢复旧数据 | 权限变更清空策略缓存、字段、状态结果和编辑目标，关闭相关窗口；列表与编辑器校验账号及权限/窗口代次 |
| 策略保存完成后，通用按钮清理可能重新启用另一编辑器 | 保存状态归属于本次编辑器；旧保存不能覆盖或启用新窗口，只读账号的字段与保存控件禁用 |
| 409 后可以反复提交旧版本 | 保留输入，禁用继续保存；必须重新加载并核对当前 revision 后再次编辑。503 保留草稿并允许重试 |
| 关闭再打开同一连接、切换连接或并发刷新时，旧详情可能覆盖当前目标 | 独立详情代次和查询序号；迟到写入/查询不能更新另一窗口，也不能解除另一请求的忙碌状态 |
| 断开请求响应丢失后，关闭详情或查看另一目标会丢失幂等键 | 按目标保留 request key 和原始原因；同一次不确定请求重试复用它们。终态后新尝试生成新键 |
| 上一条失败指令的迟到列表可能清除新尝试的键 | 记录尝试前的指令 ID 和收到的指令 ID；旧终态不被当作新尝试已结束，增加独立回归 |
| 多次查询失败后轮询停止，已受理状态也可能被隐藏 | 短暂失败持续重试；POST 成功立即显示已受理，再查询结果；403/404 停止并禁用操作，关闭或撤权停止轮询 |
| 离线主机的指令已超时，列表仍显示排队，详情才显示过期 | 共享连接视图按服务端当前时间投影 queued/delivered 为 expired；全局、组、设备集合列表一致。只改变指令状态，不伪造连接关闭或回执 |

断开确认改为详情内显式勾选“我已核对上述设备与连接 ID”。原提示主要显示查看者/地址，不能充分区分同一查看者的多条连接；新交互让设备、连接 ID 和确认保持在同一窗口。未勾选、关闭或 Escape 均不发起指令；排队/已投递时禁用再次请求。之前 IAB 的原生确认框控制限制仍属于工具限制，不据此认定 `window.confirm` 本身有生产故障。

## 3. 浏览器实际结果

使用虚构账号 manager、reader 和模拟设备 eastbox、westbox。两台模拟设备各有 A/B 两条连接，分别展示直连和中继。测试 API 用于制造并发修改和撤权，策略编辑、断开请求、取消及页面读取由浏览器完成。

| 场景 | 实际结果 |
| --- | --- |
| 无策略回执 | 主机与查看端分别显示“尚无当前版本的应用回报，不能确认已生效” |
| 主机待重启与已应用回执 | 签名 pending_restart 显示待重启；签名 applied 显示已应用。查看端仍独立显示未回报 |
| 保存 503 后恢复 | host.keep_awake 草稿保留、保存按钮恢复；解除故障后保存成功，提示仍需客户端确认 |
| 策略更新后旧回执 | 主机 revision 递增后不再使用旧版本回执；未变化的查看端配置 revision 保持不变 |
| 策略并发冲突 | 编辑 revision 2 时另一请求更新为 3；保存返回 409，草稿保留且保存禁用；重新加载显示 3 并允许核对后再编辑 |
| 只读账号 | reader 的 11 个策略 fieldset 和保存按钮禁用；活动连接无断开行按钮，详情断开表单隐藏 |
| 撤权 | manager 的策略窗口打开时由测试 API 解绑；权限轮询后窗口关闭、字段数和策略对象行数均为 0 |
| 勾选后关闭、不发送 | 再打开确认框时勾选已重置，指令仍为空 |
| queued → delivered | 页面均显示断开待确认，未显示成功，发送控件保持禁用 |
| applied 与精确缺席回执 | 模拟目标从快照消失且签名回执确认不存在后，详情显示“已确认断开”；其他三条模拟连接保持活动 |
| POST 响应丢失且连续 GET 503 | 页面保留错误并持续重试；解除故障后自动显示签名 failed 回执，连接仍活动 |
| 明确失败后的新尝试 | 重试产生不同的 command ID；未投递时仍显示排队 |
| 真实 60 秒截止时间 | 初次复现列表/详情不一致；修复后在新构建发送指令，关闭详情并暂停主机，截止后仅进入列表即显示已过期。连接仍为心跳过期，未显示确认断开 |

浏览器截图和运行日志在 `build/s01-s02-console-20261117/`：

- `strategy-status.jpg`：主机当前版本的模拟应用回执与查看端未回报状态；
- `connection-confirmed.jpg`：模拟目标签名回执后的确认状态；
- `connection-expired.jpg`：修复后无需详情查询即可显示指令过期；
- `browser1.log`、`final.log`：两轮临时服务正常退出；夹具 PASS 只表示正常运行/清理，不代表自动化浏览器验收。

最终浏览器复验使用 `final/`（API 53422、页面 53431）。策略及超时交互复验后，另补旧失败指令不清除新键的前端保护，以确定性 Node 回归验证；没有把该补丁写成再次完整浏览器复跑。最终浏览器未记录 JavaScript error。测试标签已关闭，两个临时服务已停止，52363、52376、53422、53431 均不再监听。
