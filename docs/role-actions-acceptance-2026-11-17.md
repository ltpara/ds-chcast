## 1. 本轮结论与范围

角色删除、global/group/object 解绑、取消、失败重试、版本冲突、最后管理员拒绝和解绑自身后的权限收敛，已通过真实浏览器验收。登录和角色页面的 320、375、768、1280 像素宽度及主要键盘/焦点路径已检查。此结论不扩大为所有管理台页面、所有浏览器、屏幕阅读器或生产部署均已验收。

前轮 `window.confirm` 导致浏览器控制超时的记录保持为历史工具限制。本轮替换确认交互有独立产品依据：旧解绑提示不包含范围，同一账号同一角色的多条绑定无法在确认时区分；页面需要明确目标、就地呈现失败、可预测的取消焦点和会话失效处理。未据工具超时认定原生确认框本身存在生产故障。

## 2. 修复内容

- 删除和解绑改用带可访问名称、目标说明的 HTML `dialog`。删除提示全部绑定会级联删除；解绑显示账号、角色 ID、范围、范围值及对象类型，并说明只删除这一条绑定。
- 默认聚焦“取消”；Enter 默认取消，Escape 和取消按钮均可关闭，Tab/Shift+Tab 在可用按钮间循环。成功提交前保留目标，错误在确认框中展示；提交期间禁用按钮并阻止 Escape，避免把已发送请求误解为取消成功。
- 打开时捕获角色 revision；轮询不得更新待确认版本。409/428 禁止继续提交旧版本，提示取消、刷新、核对后重新操作；404 提示目标已不存在。
- 撤权、退出/换号使确认状态失效并清除目标；旧请求完成后不能关闭新账号的确认框。成功写入后立即刷新自身权限，再决定是否加载角色列表。
- 编辑后焦点进入名称；清空后进入 ID；重新载入后进入名称。列表轮询保留权限复选框/行按钮的逻辑焦点，取消后回到对应行，目标删除后回到对应列表的刷新按钮。后台查询不再通过禁用刷新按钮夺走焦点。
- 修正角色表单最小列宽导致的整页横向溢出；绑定输入可收缩，确认框长目标可换行，按钮有可见键盘焦点。两张角色表支持键盘进入横向滚动区域。
- 修正窄窗口登录栏溢出并给输入保留可用宽度。角色权限标签改为换行，桌面表格从约 2304 像素收敛到 1199 像素（1280 视口），操作列可见。

仅修改管理台资源、相关回归与手动验收夹具；未修改本轮之前的后端权限/版本契约，schema 仍为 v26。

## 3. 实际浏览器证据

使用隔离 loopback 夹具、真实 API、SQLite 账号存储和内存注册表。账号及测试角色全部为虚构数据。测试 API 仅用于准备角色/绑定、制造并发修改和调整独立管理员；表中删除、解绑和取消均由浏览器操作完成。

| 场景 | 观察结果 |
| --- | --- |
| 删除默认取消 | 打开 `cascade-review` 删除框，默认焦点为取消；Enter 关闭，角色与绑定保留，焦点回到删除按钮 |
| 解绑范围说明与 Escape | `ordinary/action-review/object/eastbox/device` 全部可核对；Tab 到确认，Escape 关闭，原绑定仍在，焦点返回对应解绑按钮 |
| 按钮取消 | group 绑定点击取消后目标保持，焦点回到对应行 |
| 503 后重试 | object 解绑返回测试 503，弹框、目标和错误保留，三个范围均未被移除；解除故障后重试成功 |
| 延迟提交 | 请求延迟 4 秒期间两个按钮禁用，显示“正在提交”，Escape 不关闭；完成后仅 object 绑定消失，global/group 仍在 |
| 各范围解绑 | 随后分别确认 group、global，最终 `action-review` 的三条绑定清零 |
| 角色删除级联 | 确认删除 `cascade-review`，角色行及其 global/group 两条绑定一起消失，出现成功提示 |
| 确认期间版本变化 | 打开 `action-review` 删除框后用测试 API 更新名称/revision；确认旧版本返回冲突，目标保留为打开时内容，确认禁用，角色未删除 |
| 最后完整管理员保护 | 将独立 root 暂时调整为 user 后，解绑 manager 被服务端拒绝，错误显示且绑定保留；恢复 root 后可重试 |
| 解绑自身 | 恢复 root 后在 manager 弹框重试成功；立刻清空角色/绑定行并隐藏角色页签，无需等 15 秒轮询 |
| 确认期间被撤权 | 最终构建中 manager 打开 scoped-reader 删除框，root 通过测试 API 撤销 manager 绑定；权限轮询后确认框自动关闭、目标文本和角色行清空，scoped-reader 未被删除 |
| 响应式 | 320/375/768/1280 视口下角色页 document scrollWidth 等于 clientWidth，表格只在自身容器横向滚动；375 登录输入宽度恢复可用 |
| 键盘编辑 | 点击编辑后名称获得焦点，Tab 到说明再到首个权限，Space 可切换权限 |
| 轮询与确认焦点 | 权限勾选和焦点经历轮询仍在；最终构建的 Shift+Tab 从取消到确认、Tab 回取消均通过；删除后回到刷新按钮，经历轮询仍保留焦点 |
