## 结论

登录设备白名单对公网或团队部署的远控服务最有安全价值，但必须同时提供可用的管理员恢复路径。邮箱邀请与验证主要服务多用户账号运营；安全告警邮件主要服务持续运维。三者都不替代远控连接可靠性、权限边界、会话撤销和发布前真实环境验收。

| 能力 | 建议优先级 | 使用场景与产品决定 |
| --- | --- | --- |
| 登录设备白名单 | 联网/团队部署 P1；个人自托管 P2 | 可限制泄露凭据在未知设备上的使用。保持用户主动启用；登记、撤销、设备丢失和管理员恢复须形成完整闭环，避免锁死账号。 |
| 邮箱验证与邀请 | 多用户部署 P2；单用户自托管可选 | 邀请适合管理员管理团队账号；邮箱验证仅在邮箱承担找回或安全通知时是必要前置。SMTP 不可用时应明确标记能力未配置。 |
| 安全告警与邮件通知 | 管理台告警 P2；邮件通知 P3/运维增强 | 先确保关键安全事件在权限范围内可检索；邮件只发送少量高价值事件。需要定义去重、风暴控制、失败重试后的重复投递语义及环境留存值，防止告警疲劳。 |

## 已完成的产品功能

- **S05 安全告警：**独立告警事件、审计来源分类与去重、独立留存、分页/筛选/CSV API、管理台列表、持久邮件任务、数据库租约和退避重试、账号订阅偏好均已接通。触发覆盖访问拒绝、应急访问、阈值锁定，以及成功的账号安全、管理员权限、主机策略/设备状态和签名密钥变更。待运维确认告警目录、风暴控制、重复投递语义和生产留存值。
- **S06 邮箱验证与邀请：**schema v30/v32 的 SQLite/PostgreSQL 迁移、邮箱变更后验证状态重置、仅存哈希的单次验证码、管理员创建/查看/撤销邀请、一次性接受并在同一事务内创建普通账号和验证邮箱均已实现。Flutter 找回邮箱、管理台“我的账号”和公开接受页已接通。
- **v33 登录设备白名单：**短时单次 Ed25519 签名挑战已接入密码、LDAP、OIDC、WebAuthn 登录；Windows 安装密钥由 DPAPI 保护；用户可登记、查看、启停策略、撤销设备并复制公钥。管理台账号列表现有“登录设备”管理入口，支持查看、粘贴公钥登记、启停白名单及撤销。全局 `accounts.read` 控制读取，`accounts.write` 控制变更；无设备时不能启用，启停和撤销前提示会话影响。
- **安全密钥回归：**既有 WebAuthn 登录流程测试已注入无设备证明测试 provider，避免将 WebAuthn 响应误作为设备签名返回值；设备证明 API 路径有独立测试覆盖。
